# v0.3.2 界面与服务控制验证

日期：2026-09-13。

- 右上角缩小面板，可通过浮动按钮或原快捷键重新展开；实时预览紧接说明文字下方。
- 在线时显示终止服务，启动和终止过程互斥，失败可重试。
- 认证的关闭接口先停止采集、提交尾音任务，然后正常退出；未完成识别和润色持久化保留。
- 模型只在 PID、进程创建时间和路径全部匹配本项目启动记录时关闭。旧版启动器没有该记录的模型保持运行。
- 独立发布目录构建 Windows x64 自包含服务，ZIP 附带安装入口及 SHA-256 校验文件，不打包本机密钥、配置或录音。

验证结果：14 项编辑器单元测试通过；服务回归检查全部通过，涵盖尾音、WAV、暂停、恢复和润色持久化。Headless Edge 加载真实面板代码，使用模拟服务验证布局、缩小/展开、终止失败重试、按钮忙碌状态及重启。

独立目录运行发布版服务，验证未认证终止返回 401、认证关闭正常退出（退出码 0）、本项目记录的模型进程退出、过期 PID 身份不被终止、重复终止无害。发布版安装和卸载在模拟 Typora resources 目录中验证，原有页面内容保留。

发布包构建阶段没有替换用户正在使用的 Typora 或运行中的服务，也没有采集真实麦克风进行验收。

## 本机安装升级

按用户后续要求，备份旧插件与服务文件后，将新版插件安装至 `C:\Program Files\Typora\resources\typora-asr`，逐文件哈希与源码匹配。确认旧服务没有活动会话后替换发布版服务，保留本机 `.asr`、模型及配置。新服务健康检查返回 `canShutdown: true`，本地模型健康检查通过。Typora 经正常关闭后重新启动。现有模型通过原有项目 PID 记录、可执行路径及模型参数核对后补录创建时间，支持新版终止按钮关闭。

## 缩小与关闭交互修正

缩小后保留一行矩形标题栏，按钮变为展开，右侧增加关闭按钮。关闭前提示 `Ctrl + Alt + R` 可恢复，并说明录音和服务继续运行；取消时保留窗口，确认后隐藏面板与浮动入口。快捷键可从缩小或关闭状态恢复完整面板。卸载面板实例时移除快捷键监听，避免重复监听。

Headless Edge 验证缩小后仍可见且高度小于 70px、宽度小于 300px，关闭按钮位于展开按钮右侧；展开恢复、关闭取消/确认、关闭后快捷键恢复均通过，窗口操作没有触发服务启停。14 项编辑器回归测试通过。
