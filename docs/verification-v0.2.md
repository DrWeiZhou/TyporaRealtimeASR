# v0.2 验证记录

日期：2026-09-12。Windows x64、Typora 1.14.10、.NET 10。

## 已验证

- 编辑器与启动器自动测试：9 项通过，包括未润色内容禁止入文、重复事件去重、人工删除与未知插入状态、IME/文档切换延迟，以及隐藏启动和防重复启动。
- 服务测试：原有 SSE/VAD/音频持久化/重采样/恢复测试通过；新增 Windows DPAPI 配置保护、原文不变、失败阻止入文、手工重试、有序放行、重启复用、暂停时间映射、有限重试和在途请求与重试互斥测试通过。
- 实际 WASAPI：两次暂停续录、暂停期间样本不增长、无效设备重试后可续录、结束状态及电平归零通过。使用临时目录，未混入用户录音。
- 隔离 Typora 窗口：确认带时间范围的润色结果入文、原文未入文、人工未保存改写保留、磁盘保存与恢复去重，原文查看包含实际时间戳。模拟润色结果用于此项，不代表真实在线模型联调。
- 代码审查后补测后台刷新期间暂停/结束仍发送请求，并保护新状态免受旧轮询响应覆盖。
- Windows PowerShell 5.1 启动脚本可执行，运行中的服务得到复用；启动器使用固定脚本、隐藏窗口和跨进程启动互斥。

## 限制与部署状态

- 未提供真实在线 API 凭据，因此在线请求使用可控模拟响应验证；真实服务的兼容性、延迟、费用与润色质量需用户在本机配置后测试。
- 未完成连续两小时、断电、磁盘满和各类真实中文输入法候选窗的全面测试。
- 测试期间发现旧版服务仍有录音在运行，未强行停止。新版构建保存在 `runtime/publish-next`，正式运行目录的切换需在旧录音结束后进行。
- API 与插件需一起升级为协议版本 2；新版插件会提示重启旧版服务。
