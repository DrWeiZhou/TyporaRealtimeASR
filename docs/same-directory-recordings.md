# 录音与逐字稿保存调整

> 2026-09-16 更新：新录音不再保存在 Markdown 同目录，改为保存到“资料记录目录”（默认 `~/.TyporaASR/RecordData`，可在面板中修改，见 `StorageSettings`）。已有会话按 `.asr/session-files` 中记录的路径继续使用原文件；以下为原设计记录。

按用户明确要求，录音及原始逐字稿保存到绑定 Markdown 所在目录，录音使用标准 WAV。每会话名称为 `<文档名>.录音-<会话ID>.wav` 和 `<文档名>.逐字稿-<会话ID>.md`，避免覆盖其他会话或主文档。

WAV 使用 PCM16、16kHz、单声道。持续写入时刷新文件头长度，暂停续录追加原文件；恢复时依据实际负载修复未完成更新的长度字段。旧 PCM 流式转换后校验样本长度，成功后原子替换目标文件，旧文件保留作备份。

数据库、API 密钥与恢复元数据仍在项目 `.asr` 内。目标 Markdown 仍只由 Typora 编辑保存。本次不改变已绑定文档的另存为/改名规则。

验证 WAV 头、采样一致性、续写、崩溃后长度修复、旧 PCM 转换、同目录逐字稿及现有录音/编辑保护回归。

以上自动测试已通过。已启用新版服务，原有在内存中的会话恢复时转换到文档同目录，历史未恢复会话将在下次恢复时转换。旧文件保留。
