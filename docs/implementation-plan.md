# 实施计划

设计已由用户于 2026-09-12 确认。当前实现过程不修改用户现有记录文档。

1. 核验并复用本机模型，在独立 Typora 测试文档验证最小范围编辑、撤销、光标保持及保存。
2. 建立 .NET 服务、JavaScript 插件与测试入口。先写测试，覆盖 VAD 尾音、输出解析、事件持久化与去重，再实现对应模块。
3. 服务实现 NAudio 采集、原始 PCM 落盘、串行推理、预览合并、final 队列、SQLite 恢复、回环认证协议。
4. 插件实现显式文档绑定、独立锚点、安全插入、IME 延迟、事件确认、重连、停止与恢复界面。
5. 用本机模型和独立文档运行集成测试；打包启动工具与说明，记录未完成的人工验收项。

关键关卡：编辑器事务不具备实证时不开放自动写正文；保存命令和保存成功分开处理。两小时真人录音属于后续实地验收，不能以单元测试替代。

## 完成状态

2026-09-12：已完成模型复测、编辑事务验证、WASAPI 录音、显式重采样、VAD、串行识别、预览/入文、SQLite 恢复、插件面板、自包含服务与安装工具。完整模型到 Markdown 流程及关闭重开去重通过，详见 verification.md。
